Raha

A calm browser where you decide which tabs get your memory and CPU.

Raha is a free desktop browser for macOS, Windows and Linux. You set how many tabs may run, and the rest sleep. A sleeping tab’s process is closed and its memory goes back to the computer. It keeps its place, title and history, and loads again on a click.

How it works

A limit on running tabs

Six tabs run by default. Past that, the tab used least recently sleeps. A pinned tab stays awake, and so does a tab playing sound.

Each tab’s memory and CPU

A bar at the bottom lists each running tab with its memory and CPU. A site can be given its own limit: with 800 MB for *.slack.com, a Slack tab over that sleeps.

No account, no telemetry

Known ads and trackers are blocked. Search starts with DuckDuckGo.

Coming in 1.0

Version 1.0 is in development. Built so far:

  • Split view: two pages side by side.
  • Today: todos and a calendar, next to your tabs.
  • Journeys: a notebook in the sidebar for courses, books, words and a diary. It also checks pages you choose for changes.
  • Zen: only the page on screen.
  • A new design, in light and dark themes.
  • A tour and short lessons.
  • Three privacy fixes: third-party cookies blocked by default, site icons loaded without cookies, and permissions that follow the page that has loaded.

1.0 has no fixed date: it comes out when its tests pass, and plans can change before then. It will be free to use.

To hear when it comes out: on GitHub, Watch → Custom → Releases, or follow the releases feed.

Already using Raha? How to update

for this machine

macOS 13 or later

  • Apple Silicon (M1 or later) .dmg
  • Intel .dmg

Not sure which Mac? Apple menu → About This Mac. First launch: macOS asks you to confirm (how to open it).

for this machine

Windows

  • Installer .exe (64-bit)

The installer is not signed. First launch: Windows asks you to confirm (how to open it).

for this machine

Linux

  • .AppImage (any distro, x86-64)
  • .deb (Debian / Ubuntu)

AppImage: chmod +x Raha-*.AppImage, then open it. Deb: sudo apt install ./raha-*.deb.

All files are on the GitHub release page, which shows a SHA-256 checksum next to each. The .zip, .blockmap and .yml files there are for the updater; you do not need them.

Already using Raha? Update to 0.3.3. Your tabs, folders, settings and history are kept.

  • macOS: Raha does not install updates itself. Download the .dmg for your Mac above (Apple Silicon or Intel), quit Raha, open the .dmg and drag Raha into Applications. When Finder asks, choose Replace. Only the app is replaced; your tabs and settings are in a separate folder and are not touched. Then eject the .dmg and open Raha from Applications. macOS may ask you to confirm the first launch again (steps).
  • Windows, and Linux with the AppImage: with update checks on, Raha downloads 0.3.3 in the background and installs it when you quit. If it has not, quit Raha and run the new installer, or put the new AppImage in place of the old one.
  • Linux .deb: download the new .deb and install it the same way as the first one (see the Linux card above).

After the update, pages reached with Back or Forward load fresh.

Your version is shown at the bottom of Settings, under About. If the update did not happen: Help.

Privacy, briefly

  • Blocks known ads and trackers, from lists shipped with the app.
  • Sends Global Privacy Control with every request a page makes.
  • Sites ask for the camera, microphone, location and notifications through Raha’s own prompt.
  • Apart from the pages you open, Raha makes three kinds of request on its own.

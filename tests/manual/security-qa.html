P5 — permissions: Raha asks, per site (R-103)

Every request below must raise an ask in Raha's own chrome (“127.0.0.1 wants to …”) — never a system dialog, never a silent grant, no toast. What you click there is the page's answer: Always allow / Never for this site are remembered (Settings → Site permissions, remove to be asked again); Allow once lasts until you leave the page; Not now / Escape refuse this request only. A site you have not decided on reads as denied to a mere check (Chrome would say “prompt”; Electron's check hook has no third answer) and is asked the moment it actually requests.

expect: denied until you have chosen “Always allow” here, granted after — and never an ask (a check is not a request)
